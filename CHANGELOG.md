# Changelog

## 1.3.0 - 2026-07-28

- Made a beginner-first Blocks workspace the default while retaining the
  complete Advanced editor and source-aligned visual design over the same
  canonical JSON contract.
- Added a finite block catalog and starter recipes that compile atomically
  into typed, acyclic Graph nodes and edges; invalid edits never partially
  mutate the saved contract. Approval blocks emit typed durable approval
  receipts, and remove/re-add preserves connector semantics deterministically.
- Added connected block views, plain-language inspection, local issue
  navigation, visible finite costs, and bounded undo/redo that never restores
  confirmation, handoff, adapter probes, or selected routes.
- Preserved invalid but structurally readable local drafts in an explicit
  repair flow instead of silently replacing beginner work with the seed.
- Added strict Python and Node coverage for every beginner block, recipes,
  atomic rejection, removal/reconnect, history sanitization, keyboard-safe
  controls, and canonical seed synchronization.
- Reject Claude, Antigravity, Codex, or any roster adapter ID as a durable
  Graph, workstream, routing, or integration owner in both browser and runtime
  handoff validation.
- Added a complete beginner-to-runtime project usage manual and a
  maximum-potential operating guide covering architecture admission,
  capability-routed multi-agent collaboration, evidence gates, recovery,
  operating metrics, extension workflows, and troubleshooting.

## 1.2.0 - 2026-07-28

- Restored the user-supplied 1536×1024 neon architecture composition, original
  icon crops, animated lifecycle, source overlay, full-screen mode, and exact
  visual provenance while keeping every major panel linked to an editor.
- Added editable Claude, Antigravity, and Codex runtime adapter declarations,
  capability-only route requests, versioned hash-chained IPC, and explicit
  separation from durable Graph/workstream ownership.
- Added a Harness-owned adapter-readiness Graph gate between strict contract
  validation and agent work, with browser authority fixed to `UNVERIFIED`.
- Bound exported Agent Team commands with a separate SHA-256 and strengthened
  the runtime validator to reject missing/tampered commands, fixed adapter
  bindings, incompatible IPC, secrets, and self-certified readiness.
- Added adapter, command-hash, asset-integrity, and source-layout regressions;
  updated the manifest, adoption guidance, architecture boundaries, and
  design-input rights record.
